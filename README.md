## 사례에서 볼 설계 포인트

1. 계정은 KB 계정 하나, LLM 은 사내 게이트웨이로 일원화하고 예산·한도를 사용자 화면에 표시합니다.
2. 에이전트 동작은 승인 카드로 묻고, 「항상 허용」 권한은 언제든 회수할 수 있습니다.
3. 회의 녹음·받아쓰기는 PC 안에서만 처리하고, 요약할 때만 텍스트를 모델로 보냅니다.
4. 지침(AGENTS.md / CLAUDE.md)과 스킬을 재사용·공유해 개인의 업무 방식을 팀 자산으로 만듭니다.
